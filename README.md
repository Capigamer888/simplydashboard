# CarlosHub (Versión Original)

Este repositorio almacena el código fuente de la **versión original de CarlosHub**, antes de la implementación del soporte multi-motor (MySQL, PostgreSQL, SQLite, SQL Server), la consola SQL, la sanitización de inputs y la refactorización a SimplyDashboard.

## Contenido del Proyecto:
- **db_Slect.php**: Selector inicial de bases de datos locales (MySQL / XAMPP).
- **inicializaciones.php**: Script de conexión PDO a MySQL.
- **Dashboard/**: Panel de navegación y gestión de tablas.
- **Read/**: Visualización de tablas y búsqueda de registros.
- **Insert/**: Formularios de inserción de registros e imágenes.
- **Edit/**: Edición y actualización universal de registros.
- **Delete/**: Eliminación de registros.
- **Foto/**: Imágenes de prueba de la versión original.
